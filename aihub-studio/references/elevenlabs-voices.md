# ElevenLabs 预置音色库

用于获取预置音色、筛选、试听、选择和收藏。获取目录使用 AIhub `GET /e/v1/configs/elevenlabs-preset-voice-id`，复用音频 Skill 的配置链和 Key；文档说明目录查询不扣 quota。清单不是模型／账户权限白名单，仍需在业务提交时核对可用性。

先按[统一配置中心](credential-setup.md)中的实际启动命令打开完整配置页面，caller 保持 `aihub-audio`，项目使用用户业务目录。点击“ElevenLabs 默认音色”中的“打开音色库”；需要直接定位时，在启动返回的 URL 中添加查询参数 `voice-library=elevenlabs`，保留原有授权 fragment。实际返回可点击的 HTTP 页面链接，不能只给 HTML 源文件或声称页面已打开。

目录通常低频更新，不承诺固定更新周期；默认复用本机完整缓存，需要最新目录时点击“重新下载”。搜索、语言、性别、名称及分类筛选均在完整本地目录执行，不向服务端发送筛选条件。页面可试听已有样音并收藏；多语言音色可从任一语言筛选到。试听不生成新语音。样音不可用时允许继续选择与收藏，明确提示；目录暂时不可读时保留已保存值和收藏。

首次范围优先可写全局，已有主表草稿接续其明确目标；关闭／重开保留当前选择和范围。选择音色、收藏及切换范围与主表共用草稿、预览和差异决定。点击“保存并使用”只提交实际修改或明确转存的默认音色／收藏，其余草稿保留；没改收藏就不重写收藏，只改收藏就不提交音色。不同内容必须明确采用哪份；重新编辑使旧选择失效。保存后由原加载器回读实际来源，结果未知时先回读，不能直接重试或报告成功。

默认项目目标为 `.env.local.aihub-studio`，默认全局目标为 `~/.config/aihub-studio/.env`。`AIHUB_ELEVENLABS_DEFAULT_VOICE_ID` 供 Eleven Speech 使用，任务显式音色优先；对话逐段指定，收藏不自动分配角色或轮换。收藏以 `AIHUB_ELEVENLABS_FAVORITE_VOICE_IDS` 的 JSON 数组保存，项目整体覆盖全局，`[]` 可明确覆盖为空。关闭全局配置时仅提供项目保存。普通编辑只写原位置；明确切换到低层时，预览并原子清理所有遮蔽目标的高层同项，再回读确认目标生效。进程覆盖或不可写来源阻止整个切换。

目录按供应方、实际网关账号及固定查询条件隔离，保存在本机私有缓存中。首次显示加载状态，同一账号重新下载时继续浏览已有目录；失败保留该账号的旧缓存、选择和收藏，刷新不写用户配置。保存新 Key 或回读发现身份变化后，页面清除旧账号列表、详情与试听；新账号首次加载失败也不显示旧目录。账号在下载期间变化时丢弃响应并要求重新载入。空目录、首次失败与筛选无结果分别展示；每页渲染 50 条，保留中文语种名称、搜索、组合筛选、详情及真实样音入口。

首次下载与主动重新下载统一显式使用 `limit=100&offset=0`，严格按 `X-Total-Count`、`X-Limit`、`X-Offset`、`X-Next-Offset` 依次下载所有页面；下一偏移量为空才结束，包括恰好填满的末页和空目录。按返回顺序合并并保留全部原始元数据，不排序、截断或去重；全部页面、总数和进度一致后才原子替换本地目录。网络、认证、JSON、响应头或进度失败均保留旧文件；总数变化时丢弃本次下载，提示用户重新下载，下一次从 offset=0 开始，不拼接不同目录。单页请求 12 秒，所有页面及 GET 重试共享 5 分钟预算；超时后可重新下载，不回退无参全量请求。

页面空闲 60 分钟到期，按 `scripts/ui.py start|status|stop --page configuration` 核对并重开同一项目的实例。保留统一配置中心的其他设置入口。交付链接时按 UI 生命周期规则提供实际期限、当前／新会话重开请求，以及 FRP / Tailscale 跨设备提示；不默认开隧道。
