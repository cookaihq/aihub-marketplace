# Changelog

## 4.2.0 — 2026-11-08

- 支持 AIhub Studio 3.x、Tikin Social 4.x，保留此前支持的版本范围。
- 委托业务配置页时沿用目标 Plugin 的项目默认文件、来源与保存结果；Setup 不另建 `.env.setup-aihub`，不迁移或删除既有凭证。
- setup-api-key 升至 4.2.0；setup-agent-model 保持 2.2.2，其模型配置流程不变。
- Windows Codex CLI 0.166.0 默认 workspace-write 沙箱通过开发源显式加载、真实配置入口及页面 HTTP 闭环；Setup 委托、任务绑定和仅配置回读通过。独立浏览器验证两套业务页桌面及 390×844 布局。按用户本批次决定，WorkBuddy 免验；macOS 待验。未重新安装、验证隐式触发或调用线上业务。


## 4.1.0 — 2026-11-07

- Hermes 同时注册 setup-api-key 与 setup-agent-model；业务配置网页、默认设置与进度恢复沿用共享实现。
- 恢复任务绑定当前 Hermes Profile，防止跨 Profile 复用确认；业务 Key 的共享路径与原三宿主行为不变。
- setup-api-key 升至 4.1.0；setup-agent-model 升至 2.2.2，修正 Hermes 已支持 Git 子目录安装的说明。
- 本版已通过 Windows 原生 Codex、WorkBuddy、Hermes 的入口加载与本机合成配置流程；Hermes 另验证 Profile 隔离及任务身份。未调用付费业务，未验证真实线上鉴权；macOS 本轮待验，Claude Code 保持兼容但未实测。历史结果仅覆盖所列版本。

## 4.0.0 — 2026-11-06

- 业务密钥配置改为委托目标 Plugin 自带页面，保留任务、caller、保存范围、提交状态和恢复绑定。退出业务 Secret Book 及旧网页入口，不搬移或删除已有配置。
- 配置适配支持 AIhub Studio >= 1.2.0、< 3.0.0 和 Tikin >= 2.0.0、< 4.0.0；新版网页需要业务 Plugin 自带 UI。页面不显示服务地址。
- 修复 Windows 私有文件对项目所有者的访问，支持 WorkBuddy 原生后台工具的持续运行及即时启动回执。
- setup-api-key 升至 4.0.0；setup-agent-model 因共用私有文件权限修复升至 2.2.1，其客户端模型配置及 Secret Book 契约不变。
- Windows 本机回归与 Codex/WorkBuddy 验收范围见 README。本轮 macOS、真实鉴权和线上业务待验。

## 2.1.1 — 2026-10-27
