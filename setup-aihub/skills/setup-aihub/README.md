# setup-aihub

为 AIhub 创作与文档、tikin 社交媒体数据服务检查和配置本机密钥。通过完整 Setup AIHub Plugin 使用，共享代码与恢复记录。

安装提示词、三宿主入口与当前开发状态见 [Plugin 使用说明](../../README.md#让-agent-帮你安装)。加载后只说 `setup-aihub`，即可选择服务或先检查配置；预期返回实际来源和缺项，不显示密钥、不发业务请求。已有目标时说“继续”沿用原选择。

本机填写、Secret Book、文件位置与恢复边界见[完整说明](../../README.md)。1.0.0 的两个服务已通过 Windows 原生 Secret Book 真实表配置、Codex 默认沙箱与 WorkBuddy 本机闭环，Claude Code 已验证安装、发现和自然触发，配置闭环未实测。
