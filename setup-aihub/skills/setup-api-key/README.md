# setup-api-key

为 AIhub 创作与文档、tikin 社交媒体数据服务检查和配置本机密钥。通过完整 Setup AIHub Plugin 使用，共享代码与恢复记录。

安装提示词、三宿主入口与当前验证范围见 [Plugin 使用说明](../../README.md#让-agent-帮你安装)。加载后只说 `setup-api-key`，即可选择服务或先检查配置；预期返回实际来源和缺项，不显示密钥、不发业务请求。已有目标时说“继续”沿用原选择。

配置默认打开所选业务 Plugin 自带的配置中心。本人在网页填写 Key，底部固定保存栏一次保存；已有范围和实际来源沿用。没有浏览器或明确选择文件编辑时，Agent 提供完整文件路径及字段，保存后回复“继续”。

配置或修复成功后，会显示 **Plugin默认设置检查**，逐项核对指定且已安装的 AIhub、tikin 等对象。需要设置时，可以回复 **1 或“设为默认 (推荐)”／2 或“本次跳过”／3 或“不再提醒”**。用途说明使用当前 Agent 的名称和具体任务示例；选择设为默认后直接设置，不再二次确认；完成后展示实际写入的完整规则、文件位置及影响范围。已有等效规则不重复询问，检查问题不影响密钥成功结果。详见[默认设置说明](../../README.md#配置完成后的默认设置)。

本机填写、文件位置与恢复边界见[完整说明](../../README.md)。业务 Plugin 必须包含本次新增的配置中心入口；只读检查仍支持现有业务契约。当前改造尚未发布，本轮验证与历史版本记录分开说明。
