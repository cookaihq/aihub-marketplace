# setup-api-key

为 AIhub 创作与文档、tikin 社交媒体数据服务检查和配置本机密钥。通过完整 Setup AIHub Plugin 使用，共享代码与恢复记录。

安装提示词、三宿主入口与当前开发状态见 [Plugin 使用说明](../../README.md#让-agent-帮你安装)。加载后只说 `setup-api-key`，即可选择服务或先检查配置；预期返回实际来源和缺项，不显示密钥、不发业务请求。已有目标时说“继续”沿用原选择。

Secret Book 版本过低时会说明当前版本和最低要求，并提供“升级到最新版／升级到最低可用版本／手动配置”。选择手动配置后，会明确给出文件完整路径、`KEY=` 字段与应填的值；你在本机填写，保存后回复“继续”。

配置或修复成功后，会显示 **Plugin默认设置检查**，逐项核对指定且已安装的 AIhub、tikin 等对象。需要设置时，可以回复 **1 或“设为默认”／2 或“本次跳过”／3 或“不再提醒”**。用途说明使用当前 Agent 的名称和具体任务示例；选择设为默认后，先展示完整规则、目标文件及影响范围，再经你确认写入。已有等效规则不重复询问，检查问题不影响密钥成功结果。详见[默认设置说明](../../README.md#配置完成后的默认设置)。

本机填写、Secret Book、文件位置与恢复边界见[完整说明](../../README.md)。当前开发版本为 2.2.0，尚未发布；macOS 的 Codex 与 WorkBuddy 已验证合成成功文案，三宿主完整流程与实际升级尚未验收。1.0.0 旧入口的验证记录与本次新入口验收分别说明；Plugin 安装身份、业务配置位置与任务进度目录保持不变。
